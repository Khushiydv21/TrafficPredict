Project Objectives

TrafficPredict is an end-to-end Machine Learning and Time Series Forecasting system designed to forecast daily website server loads across 7-, 15-, and 30-day forward horizons.

Dataset Specification
  • Source: Historical visitor traffic from statforecasting.com
  • Timeline: 14 September 2014 to 19 August 2020 (2,167 days)
  • Continuity: 100% continuous calendar timeline (0 missing dates, 0 null values)
  • Target: Page.Loads with companion visitor metrics
Technology Stack
  • Backend: Python 3.14, Flask, Scikit-Learn, Statsmodels
  • Visualizations: Plotly Express & Plotly Graph Objects
  • Deployment: Vercel Serverless Python Engine (@vercel/python)
